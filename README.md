# EMBERWAKE

A low-poly, on-rails space shooter in the style of Star Fox 64. It is written in
Jac, compiled to a native binary through LLVM, and rendered with raylib 6.0.
Every model is generated by Blender scripts and every sound is synthesized
from code.

> *Vesper is going dark. Something is singing to it.* Escort the colony ark
> **Lantern** across a dying star system to a jump gate that has been dark for
> a hundred years. There are five chapters, three bosses and one way out.

## Play

```bash
./build.sh            # fetches raylib, generates missing assets, compiles, runs
./emberwake           # run the built game (from this folder)
```

| Action | Keyboard | Gamepad |
|---|---|---|
| Steer | WASD / arrows | left stick |
| Fire (hold to charge, release for a homing plasma bolt) | Space / J | A |
| Roll (deflects shots) | Q / E | LB / RB |
| Boost | Shift | RT |
| Brake | Ctrl / C | LT |
| Bomb | B / K | X |
| Pause | P / Esc | Start |
| Mute / fullscreen | M / F11 | |

New Game asks for a difficulty (Recruit, Guard, Ace). After each chapter you
pick one of three refit upgrades for the Kestrel. Each chapter has a medal
score, and dying after a boss appears lets you retry from that boss. Progress
is saved in `save.txt`.

## Requirements

- Linux x86_64. `build.sh` downloads the raylib 6.0 release next to the binary.
- The Jac compiler with the native backend. `build.sh` expects the dev launcher
  at `~/forks/native/jac/jac/zig-out/bin`; edit the `PATH` line if yours is
  elsewhere.
- Optional: Blender 5.2 to regenerate models, and Python 3 with numpy (plus
  ffmpeg for `.ogg`) to regenerate audio. The repository ships the generated
  models, sound effects and `.ogg` music, so neither is needed just to build
  and play.

## Layout

| Path | What |
|---|---|
| `docs/STORY.md` | Story bible: world, characters, chapters, radio script |
| `docs/DESIGN.md` | Game design: controls, enemies, bosses, chapters, art and audio direction |
| `blender/lowpoly.py`, `blender/assets.py` | Procedural low-poly modelling; every model → `assets/models/*.glb` |
| `tools/gen_audio.py` | numpy synthesizer for every SFX and music loop → `assets/sfx`, `assets/music` |
| `assets/shaders/lit.*` | Flat lighting, rim light, emissive faces, fog, hit flash |
| `game/*.jac` | The game: `rl` bindings, `gfx`, `audio`, `state`, `spawn`, `world` (chapters), `logic`, `render`, `hud`, `main` |
| `game/gallery.jac` | Model gallery (`./build.sh --gallery`) |
| `spike/` | The original Blender → glTF → raylib feasibility test |

Regenerate assets with `./build.sh --assets`. Individual models:
`blender -b --factory-startup -P blender/assets.py -- kestrel mote`.

## Testing flags

```bash
./emberwake --chapter 4 --at 0.3 --demo --frames 1200 --shot-every 300 --mute
```

`--chapter N` starts a chapter directly. `--at P` skips to progress P (0–1).
`--demo` flies an invulnerable autopilot that fires constantly. `--frames N`
runs N fixed 1/60 s steps uncapped, then exits and prints a summary.
`--shot-every K` saves `shot_c<chapter>_<frame>.png` every K frames.
`--screen difficulty|refit2|briefing3|prologue|controls|select` opens a menu
screen directly. `--pin-y Y` holds the ship at height Y. `--ss F` sets the
supersampling factor (default 1.5; use 1 on weak GPUs).

Fonts: Chakra Petch and Barlow, both under the SIL Open Font License
(`assets/fonts/OFL-*.txt`).

## Notes on Jac native

- Import names explicitly from `game/rl.jac`. `import from rl { * }` loses the
  externs' return types (E1032).
- Calling `.split()` directly on a `str` returned by a C extern is not lowered
  yet. Bind it to a typed local first (`txt: str = LoadFileText(...)`).
- Build with the fork's dev launcher (`~/forks/native/jac/jac/zig-out/bin`);
  `build.sh` sets the PATH.
